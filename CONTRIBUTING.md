# Contributing to Alya Glass

Thank you for your interest in contributing to **Alya Glass**!

Alya Glass is a BetterDiscord theme focused on a transparent glass-style interface, customization, and visual improvements. Contributions, suggestions, bug reports, and improvements are welcome.

## Getting Started

Before contributing:

1. Read this document.
2. Check existing Issues and Pull Requests.
3. Make sure your changes are compatible with the current version of BetterDiscord.
4. Test your changes before submitting them.

## What You Can Contribute

You can contribute in many ways:

* Fixing bugs
* Improving the theme's UI
* Adding customization options
* Improving transparency and glass effects
* Improving compatibility with Discord updates
* Fixing CSS issues
* Improving performance
* Adding documentation
* Reporting bugs
* Suggesting new features

## Pull Requests

When submitting a Pull Request:

1. Clearly describe what you changed.
2. Explain why the change is needed.
3. Test the changes in Discord before submitting.
4. Keep changes focused on one feature or fix when possible.
5. Do not include unrelated changes.
6. Make sure your code is readable and organized.

## CSS Guidelines

For CSS changes:

* Keep selectors organized.
* Avoid unnecessary `!important` rules.
* Avoid breaking existing customization options.
* Keep the glass/transparency design consistent.
* Test both dark and light Discord interfaces when applicable.
* Make sure text remains readable.

## New Features

Before implementing a large feature, please open an Issue first and describe:

* What the feature does
* Why it is useful
* How it should work
* Any possible compatibility concerns

This helps avoid duplicated work and allows the feature to be discussed before development begins.

## Bug Reports

When reporting a bug, include:

* Discord version
* BetterDiscord version
* Alya Glass version
* Operating system
* Description of the problem
* Steps to reproduce the problem
* Screenshots or recordings when useful

## Issues

Please search existing Issues before creating a new one.

Do not use Issues for:

* Spam
* Advertising
* Unrelated discussions
* Personal attacks
* Repeated reports

## Code Quality

Contributions should be:

* Readable
* Organized
* Tested
* Relevant to Alya Glass
* Compatible with the project's goals

## Attribution

By submitting a contribution, you agree that your contribution may be included and distributed as part of Alya Glass under the project's license.

Please do not submit code, images, fonts, icons, or other assets that you do not have permission to distribute.

## Respect Other Contributors

Be respectful when reviewing Pull Requests, discussing Issues, or suggesting changes.

Constructive criticism is welcome. Harassment, insults, discrimination, and personal attacks are not.

## Thank You

Every contribution helps improve Alya Glass.

Thank you for helping make **Alya Glass** better!
