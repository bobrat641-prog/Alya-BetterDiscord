# Security Policy

## Supported Versions

We currently provide security updates for the latest stable version of Alya Glass.

| Version        | Supported |
| -------------- | --------- |
| 1.x            | ✅ Yes     |
| Older versions | ❌ No      |

Security support may change as new versions of Alya Glass are released.

## Reporting a Vulnerability

If you discover a security vulnerability in Alya Glass, please report it privately to the project maintainers.

**Please do not publicly disclose the vulnerability before it has been investigated and addressed.**

When reporting a vulnerability, please include:

* Alya Glass version
* BetterDiscord version
* Discord version
* Operating system
* A detailed description of the vulnerability
* Steps required to reproduce the issue
* Screenshots or other relevant information, if available
* Any possible impact you believe the vulnerability may have

## Where to Report

Please use GitHub's **Private Vulnerability Reporting** feature when it is enabled for this repository.

If Private Vulnerability Reporting is unavailable, contact the project maintainer privately using the contact information provided in the repository.

## What Happens After a Report

After receiving a security report, the maintainers will:

1. Review the report.
2. Attempt to reproduce the issue.
3. Determine the severity and impact.
4. Develop a fix when necessary.
5. Release an updated version when appropriate.
6. Credit the reporter if they wish to be publicly acknowledged.

Please allow reasonable time for the issue to be investigated and fixed before making the vulnerability public.

## Responsible Disclosure

We ask security researchers and contributors to follow responsible disclosure practices.

Please do not:

* Publicly post unpatched vulnerabilities.
* Share exploit code before a fix is available.
* Use vulnerabilities to access other users' accounts or private information.
* Intentionally damage Discord, BetterDiscord, or Alya Glass installations.
* Perform actions that may harm other users or services.

Security research should be performed responsibly and only on systems you are authorized to test.

## Scope

This security policy applies to the Alya Glass project and its official repository.

Issues involving Discord, BetterDiscord, third-party plugins, external services, or other software should generally be reported to their respective maintainers.

## Security Updates

Security fixes may be released as:

* Patch releases
* Minor releases
* Major releases when necessary

Important security updates may also be announced through the project's official repository or other official project channels.

## Thank You

Thank you for helping keep **Alya Glass** safe and reliable.

Responsible security reports help us improve the project for everyone.
