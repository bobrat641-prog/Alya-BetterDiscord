# Code of Conduct

## Our Standards

The Alya Glass community is intended to be a friendly, respectful, and constructive environment for everyone.

We expect all community members, contributors, and maintainers to:

* Be respectful to others.
* Communicate constructively.
* Accept reasonable differences of opinion.
* Give useful and respectful feedback.
* Focus on the project rather than individuals.
* Respect the work and contributions of others.
* Help keep discussions relevant and productive.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment or bullying
* Personal attacks
* Hate speech or discrimination
* Threats or intimidation
* Deliberate disruption of discussions
* Spam or excessive advertising
* Sharing private or personal information about others
* Impersonating project maintainers or contributors
* Malicious behavior intended to damage the project or its community

## Project Discussions

Technical disagreements are normal.

When disagreements occur, participants should focus on:

* Facts
* Technical reasoning
* Project goals
* Possible solutions

Arguments should not become personal.

## Reporting Problems

If you experience or witness unacceptable behavior, please report it privately to the project maintainers through the contact method provided in the repository.

Please do not publicly expose private information about the people involved.

## Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.

Possible actions include:

* Warning the person involved
* Removing inappropriate content
* Closing discussions
* Restricting participation
* Temporarily or permanently banning participation in the project

The response will depend on the severity and circumstances of the violation.

## Scope

This Code of Conduct applies to:

* GitHub Issues
* Pull Requests
* Discussions
* Project-related chats
* Other spaces officially associated with Alya Glass

## Final Note

Alya Glass is an open-source project. Everyone is welcome to contribute, suggest improvements, report bugs, and help develop the project.

Treat others with respect and help keep the community welcoming.
